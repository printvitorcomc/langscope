Como interpretar esses dados

Os dados de uso vêm da Stack Overflow Developer Survey 2026 ↗, com 14.099 respostas à pergunta sobre linguagens. A dificuldade é uma estimativa educacional independente dessa pesquisa.

Pesquisa de referência

A pesquisa mostra quais linguagens os participantes usaram no último ano. Ela indica adoção entre desenvolvedores, não quantidade de vagas.

Dificuldade

Nota estimada para iniciantes, considerando conceitos (35%), sintaxe (30%), complexidade técnica (20%) e ferramentas (15%). É um guia, não uma medida científica. SQL fica sem nota.

Uso e popularidade

Uso é o percentual de participantes que utilizaram cada linguagem. Popularidade transforma esse valor numa nota de 0 a 10, com JavaScript como referência.
