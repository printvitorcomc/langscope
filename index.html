Como interpretar os dados

Dificuldade é uma estimativa de quanto uma linguagem exige de quem está começando. Quanto maior a nota, mais difícil tende a ser o início.

Uso (%) mostra quantos participantes da pesquisa disseram utilizar a tecnologia. Não representa quantidade de vagas.

Nota de uso converte esse percentual para uma escala de 0 a 10, usando JavaScript como referência.

A dificuldade considera conceitos (35%), sintaxe (30%), complexidade técnica (20%) e ferramentas (15%). É uma avaliação orientativa, não uma medição científica. SQL não recebe nota porque funciona de maneira diferente.
